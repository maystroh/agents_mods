# Screen share

When the user asks for a share-safe artifact, create a separate redacted copy and preserve the original. Mask email addresses, phone numbers, monetary amounts, and any names or terms the user identifies. Review the result for remaining sensitive details in context; regex replacement alone is insufficient. Mark redactions visibly so the copy is clearly altered.

For images or screen recordings, use an image editing or video workflow that can produce a verified redacted copy. Never claim the Codex interface itself is masked: this skill cannot draw Claude's live overlay over the app. If the request is only to toggle a live overlay, explain that limitation and offer a redacted artifact.
