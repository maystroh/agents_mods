# Chat inventory

Build an inventory from the visible chat, available chat history or transcript, and workspace evidence. Group actual usage into connected services and tools, skills, and files. For each item, give a short reason it was used; include counts only when the source supports them.

Distinguish used items from merely available ones. If older chat history or some tool calls are unavailable, label the inventory partial. Avoid opening sensitive file contents just to populate the list. Present the inventory inline; Codex does not expose Claude's custom side pane to skills.
