# Helper desk

For a multi-step task, keep a short set of concrete milestones and update the user as work moves between them. Report completed, active, and blocked steps using evidence from the current task. When subagents are actually running, report their status and outputs without inventing activity or percentages.

Use the native plan or commentary surface available in the session. Do not create subagents solely to populate a progress view. On a status request, answer briefly and continue the original work. Codex does not support this Claude mod's persistent prompt bar or subagent cards through a skill.
